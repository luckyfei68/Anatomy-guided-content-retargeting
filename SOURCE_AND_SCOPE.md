# Source and scope

The result CSV files are direct table-text exports from the manuscript file
`AGCR_BSPC_latest_revised.docx` (SHA-256 `58ee38f6ef171fea7f20768e522ac98e7a72a9f72974786498d8ff62139216af`). The five
tables contain cohort summaries and displayed confidence intervals; no
additional statistics were calculated for this release. Some cells contain
multiple values exactly as typeset in the manuscript.

This release does not include the DICOM/UID selection manifest, segmentation
or seam-carving code, patient-level inputs or outputs, nodule XML matching,
statistical scripts, or the visual-preference answer file. Therefore no
end-to-end reproduction claim is made.
