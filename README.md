# Anatomy-guided content retargeting for chest CT preview

This repository provides selected materials accompanying the manuscript
*Anatomy-guided content retargeting for chest CT preview*.

## Contents

- `results/`: values transcribed from the five numerical tables in the
  manuscript version used to prepare this release. Percentages, paired
  differences, and confidence intervals retain the manuscript's rounding.
- `SOURCE_AND_SCOPE.md`: source checks and the limits of this release.
- `SHA256SUMS.txt`: hashes for the public files.

The original CT data and reader annotations are supplied by the public
LIDC-IDRI collection through The Cancer Imaging Archive (TCIA). No DICOM
images or participant-level visual-preference responses are included here.

**Scope:** The tables allow inspection of the reported aggregate values.
They do not contain patient-level outcomes, saved seam paths, segmentation
masks, resampling draws, source code, or the preprocessing/analysis pipeline.
This repository alone cannot reproduce the patient-level experiments or their
confidence intervals. See the manuscript's Data availability statement for
access to other research materials.

The LIDC-IDRI dataset is governed by its own terms.
